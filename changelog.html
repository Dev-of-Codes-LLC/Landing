What's been shipped, in order.

Across the site and the projects on it. Newest first. Updated when something worth noting lands.

Oct 2026Site

Contact form moves off Formspree Site

Submissions now go to a small function in the site's own AWS account, which emails them to my inbox from the site's domain. No third-party form service, a hidden-field and timing check against bots, and the function only accepts requests the site's CDN has signed.

Oct 2026Site

devofcodes.com rebuilt as a one-person company site Site

The previous homepage described a product with founding customers and a pricing page. Neither existed. The site now says what's true: one developer, four projects with honest statuses, and a clear way to hire me. Backgrounds are rendered live with WebGPU using the open-source shaders library, with CSS fallbacks everywhere.

Oct 2026Open Editor

Open Editor Platform research plan Plan

A research and implementation plan for a fully open-source editor SDK serving developers and book authors equally. Engine survey, architecture contracts, release gates and a twelve-month delivery plan, with sources. Read it here.

Oct 2026BBI

Instruction book change marking; phase 5 under way In development

The instruction book now marks what changed between revisions. Phases 1 to 4 (design studio, voxel engine, build intelligence, instruction factory) are delivered; phase 5, the revision engine, is in progress.

  • Instruction book with chapters, steps, camera hints and quality checks
  • Bill of materials, BOM deltas, build statistics and build progress
  • A feature guide page shipped with every delivered feature
Sep–Oct 2026DFS Command Center

Results, Slate Radar, optimization, routines In daily use

The blueprint's 27 units are complete, plus the v2 data track and the first v4 operations units. Results now import from both platforms' account history and reconcile against the ledger.

  • Lineup generation with OR-Tools CP-SAT; portfolio optimization with HiGHS
  • Contest evaluation with Monte Carlo and model uncertainty reported separately
  • Public sports data ingestion with provenance, freshness thresholds and reconciliation checks
  • Daily routine checklist with deadlines derived from recorded slate locks
Mar 2026Platform

Platform prototype runs end to end Prototype

Identity, Control Plane, Gateway, Audit and Falcon come up from a single compose file. Multi-tenant isolation with PostgreSQL row-level security, MFA and step-up authentication, policy-driven rate limits, an append-only audit log, and observability with Prometheus and Grafana. Falcon works locally and has no users.
