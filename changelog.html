What's been shipped, in order.

Across the site and the projects on it. Newest first. Updated when something worth noting lands.

Oct 24, 2026Site

The home page leads with where each project stands

The home page opens with "Work you can inspect." and a plain status board for every project, with the newest log entries under it. Projects are ordered by how real they are: DFS Command Center and BBI in full, the platform and the Open Editor plan as one row each.

WhyThe status record says what only DevOfCodes can say, so it now opens the home page instead of sitting a click away.

  • Amber marks what you can act on, cyan marks links, and status colours appear only on status pills
  • Small labels meet WCAG AA contrast, and an empty contact form says which fields are missing
  • Only the hero keeps a live WebGPU background; covers that didn't show the work are gone
Oct 17, 2026Toolkit

The AI toolkit is public In daily use

The Claude Code skills and agents that plan, ship and document the work here are now an open-source repo under the MIT licence, with my own names and accounts taken out. Each one says what it will not do. See the toolkit page.

WhyOne public repo can't drift from the tools in use the way a cleaned-up private copy would.

  • devofcodes-dev-workflow: feature docs, landing a branch, Docker cleanup
  • devofcodes-repo-ops: ticket writing, a status digest, an org map and a read-only backlog planner
  • Renamed on 2026-10-24: the plugins now carry the publisher's name (devofcodes-dev-workflow, devofcodes-repo-ops, devofcodes-own-it), so each one is distinct in Anthropic's plugin directory. Skills kept their names.
  • CodeQL and link checks on every change; the site's toolkit page builds its catalog from the repo at deploy
Oct 17, 2026Site

New offer: AI platforms and integrations

Work with me now includes connecting model APIs to your own data and systems, with structured outputs, permission boundaries, evaluation sets and cost limits written as code, or setting up your team's AI coding tools. The site's motion also moved onto the transitions.dev timing tokens.

Oct 11, 2026Platform

CI repaired across the platform repos Prototype

Pull request checks build and test again on Identity, Control Plane, Gateway, Audit, Falcon and the end-to-end suite. Every GitHub Action is pinned to a commit SHA, and Dependabot keeps those pins and the dependencies current.

WhyCI had failed on every pull request in five of the six repos, one of them since February.

Oct 10, 2026Site

Contact form moves off Formspree

Submissions now go to a small function in the site's own AWS account, which emails them to my inbox from the site's domain. No third-party form service, a hidden-field and timing check against bots, and the function only accepts requests the site's CDN has signed.

WhySubmissions should reach the hello@ inbox without a third-party service, a monthly cap or another company's privacy terms in the way.

Oct 10, 2026Site

devofcodes.com rebuilt as a one-person company site

The previous homepage described a product with founding customers and pricing. Neither existed. The site now says what's true: one developer, four projects with honest statuses, and a clear way to hire me. Backgrounds are rendered live with WebGPU using the open-source shaders library, with CSS fallbacks everywhere.

WhyThe site should match reality, and the old one described a billed service that did not exist.

Oct 10, 2026Open Editor

Open Editor Platform research plan Plan

A research and implementation plan for a fully open-source editor SDK serving developers and book authors equally. Engine survey, architecture contracts, release gates and a twelve-month delivery plan, with sources. Read it here.

WhySophisticated editing should be easy to integrate, reliable, portable and fully open source.

Oct 9, 2026BBI

Instruction book change marking; phase 5 under way In development

The instruction book now marks what changed between revisions. Phases 1 to 4 (design studio, voxel engine, build intelligence, instruction factory) are delivered; phase 5, the revision engine, is in progress.

WhyA builder partway through the old book got a new book with every step unmarked and progress at zero; now they keep their place.

  • Instruction book with chapters, steps, camera hints and quality checks
  • Bill of materials, BOM deltas, build statistics and build progress
  • A feature guide page shipped with every delivered feature
Sep 30, 2026DFS Command Center

Results, Slate Radar, optimization and routines ship In daily use

The blueprint's 27 units are complete, plus the v2 data track and the first v4 operations units. Results now import from both platforms' account history and reconcile against the ledger.

WhyThe point is less research and lineup work, with every recommendation traceable, reproducible and measurable.

  • Lineup generation with OR-Tools CP-SAT; portfolio optimization with HiGHS
  • Contest evaluation with Monte Carlo and model uncertainty reported separately
  • Public sports data ingestion with provenance, freshness thresholds and reconciliation checks
  • Daily routine checklist with deadlines derived from recorded slate locks
Mar 1, 2026Platform

Platform prototype runs end to end Prototype

Identity, Control Plane, Gateway, Audit and Falcon come up from a single compose file. Multi-tenant isolation with PostgreSQL row-level security, MFA and step-up authentication, policy-driven rate limits, an append-only audit log, and observability with Prometheus and Grafana. Falcon works locally and has no users.

WhyThe full stack had to run locally with one command.
